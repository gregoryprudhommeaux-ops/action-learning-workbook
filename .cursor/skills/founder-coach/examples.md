# Founder Coach — exemples d’invocation

## Alexandre-Focus-Coach (/focus)

> Alexandre-Focus-Coach — j’ai La Mesa, wine EU, et 4 idées IA ouvertes. Aide-moi à trancher les 12 mois.

> /focus

Attendu : reformulation courte · 1–2 insights · 2–4 questions · micro-action. Pas de plan GTM.

## Joe-Strategie-Coach (/offre)

> Joe-Strategie-Coach — Clarifie La Mesa comme offre vendable (pas comme liste CRM).

> /offre

Attendu : Diagnostic → Angle → Recommandation → Plan → Asset pitch + enabledPlays (2–3).

## Bridge CRM

> Joe — après OFFRE, donne le bloc Projet CRM prêt à coller (pitch + plays + critère shortlist).

## SYSTÈME (seulement après clarté)

> Concevoir un agent qui prépare les cartes Avancer du matin pour le projet X.

Attendu : fiche agent + garde-fous ; refuser si l’offre n’est pas claire.
