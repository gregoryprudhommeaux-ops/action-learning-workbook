# Founder Coach — référence détaillée

Complément de [SKILL.md](SKILL.md). Lire seulement si le mode actif a besoin de profondeur.

## Synthèse FOCUS (corpus)

Utiliser comme **lenses**, jamais comme citations :

| Lens | Usage concret |
|------|----------------|
| Ikigai | Intersection utile / payé / bon / monde a besoin — pour trancher un chantier |
| Frankl | Sens > distraction ; ce qui donne une raison de tenir 10 ans |
| Dweck | Expérimenter 30 jours > identité figée “je suis multipotentiel” |
| Brown | Vulnérabilité = dire non aux projets pour être vu sur un angle |
| Tracy / Branden | Confiance via engagements tenus (micro-wins), pas via nouveaux projets |
| Robbins | Leviers : focus émotionnel sur 1 résultat visible |
| Sinek | WHY du cap 12 mois avant tactiques |
| Burkeman | Temps fini → dire non est stratégique |
| Hendricks | Zone de génie vs zone de compétence (où tu restes dispersé) |
| Bungay Stanier | Questions > conseils ; “What’s the real challenge here?” |
| Cameron | Matin pages / recovery si blocage créatif — optionnel |

## Synthèse OFFRE (principes Company of One)

- Partir petit, définir la taille volontairement.
- Apprendre vite avec des offres testables.
- Actifs réutilisables : pitch, frameworks, démos, contenus, agents.
- IA = levier sur delivery / reach / clarté — pas le produit sauf si c’est le cœur prouvé.

## Critères de scoring d’une idée (0–2 chacun)

Clarté positionnement · Simplicité exécution · Rapidité test · Monétisation · Reach · Crédibilité profil · Lean / Co1 · Automatisation intelligente · Actifs réutilisables · Cohérence internationale.

**Seuil :** &lt; 12/20 → reformuler ou tuer.  
**12–15** → lean test 30 jours.  
**16+** → standardiser + CRM projet.

## Exemples de recadrage CRM

| Symptôme | Diagnostic | Next |
|----------|------------|------|
| File Avancer pleine, “je ne sais pas quoi faire” | Offre / pitch flous ou 1 seul projet ops | OFFRE sur 1 chantier ou FOCUS pour couper |
| Tous les contacts “La Mesa” | Un seul projet actif alimente la file | Créer 2e chantier ou pause + pitch |
| 10 projets “actifs” | Dispersion | FOCUS → max 3–5 active |
| “On construit un agent d’abord” | Outils avant offre | OFFRE d’abord |

## Anti-patterns

- Mega-prompt unique sans mode → réponses molles.
- Automatiser la prospection avant message clair.
- Shortlist ★★★ sans critère (remplit Avancer de bruit).
- Plays tous activés (present+invite+email+follow_up+meet) dès le jour 1.
